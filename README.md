# 🎨 VectorAI - Vetorizador Profissional com IA

Transforme imagens raster em vetores perfeitos (SVG, EPS, PDF, DXF) com isolamento inteligente de fundo e super-resolução.

🌐 **Acesse a Aplicação Oficial:** [https://4u.ia.br/app/vetor/](https://4u.ia.br/app/vetor/)

---

## ✨ Recursos

- 🚀 **Motor VTracer WebAssembly:** Vetorização ultrarrápida nativa em Rust/WASM diretamente no navegador.
- 📐 **Geometrização & Snapping:** Ajuste ortogonal de ângulos de 90°, detecção de círculos/elipses e suavização de curvas de Bézier.
- ✂️ **Recorte de Fundo Inteligente:** Isolamento cirúrgico de fundo periférico (fake PNG checkerboard, fundos sólidos e gradientes).
- 🔍 **Super-Resolução 4x (Real-ESRGAN):** Restauração de arestas e remoção de ruído antes da vetorização.
- 💾 **Exportação Industrial:** Suporte a SVG, EPS, PDF e DXF para corte a laser, plotter e edição gráfica (Illustrator/CorelDRAW).
- 📱 **Progressive Web App (PWA):** Instale como app no desktop ou celular para uso offline.

---

## 🛠️ Tecnologias

- **VTracer (Rust/WASM):** Algoritmo de traçado vetorial sub-pixel.
- **ONNX Runtime Web:** Modelos de inteligência artificial no cliente.
- **HTML5 Canvas & Web Workers:** Processamento multithread assíncrono e de alta performance.
